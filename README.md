- advanture-camp
- Program Adventure Camp adalah aplikasi konsol berbasis bahasa C yang dirancang untuk mendigitalisasi sistem penyewaan perlengkapan berkemah secara interaktif. Aplikasi ini menyediakan fitur utama berupa daftar peralatan, pemesanan otomatis dengan kalkulasi diskon berdasarkan durasi sewa, pencetakan struk transaksi, serta penyimpanan riwayat transaksi beserta total pendapatan menggunakan array.
